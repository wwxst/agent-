**2026-10-31 仓库清理说明：** 当前分支已移除所有应用和包源码、测试程序、构建配置、自动化工作流及研究探针脚本。仓库不再提供可编译或可运行的 Agent 内核，历史文档中提到的“已实现”“已测试”“代码路径”“运行命令”等，均是清理前版本的历史记录，不表示当前文档分支存在相应源码或可复现测试。
