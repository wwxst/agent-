# 模型适配、上下文与扩展设计

> 推荐设计草案；并非当前实现声明。

## 模型适配

Provider 统一模型输出、工具调用和用量事件，必须明确流截断、非法片段、取消、超时以及未提供用量时的预算语义。模型不得直接驱动工具或赋予权限。切换模型时不复制整套状态机；厂商能力不支持时明确报错。

## 上下文投影

构建模型上下文时合并用户消息、可验证历史摘要、工具返回及授权范围内的系统指令。摘要/Checkpoint 不覆盖原始事件；压缩器失败不能越过工具执行或持久化屏障。模型可见 ToolResult 可按原始调用次序稳定输出，可信收据仍应记录真实完成顺序。

## 工具目录与 Step 快照

每个模型 Step 冻结工具名、版本、Schema 与策略可见性；执行前独立比对工具定义和授权。模型生成的工具参数片段尚未完整前，任何 Host 不得启动副作用。

## 扩展与多智能体

Skills、Hooks、MCP、Subagents 和动态能力 Scope 可以增强功能，但应继承或收紧父级身份、权限、预算与取消语义。扩展卸载必须 Drain 已启动任务，不得隐藏未决结果或绕过可信 Host。

## 当前未决事项

1. 对原生 Agent Loop 的复用策略：自研、Pi Core 薄适配或其他方案。
2. 模型 Usage 未提供时是否强制拒绝硬 Token 预算。
3. 如何兼顾并行工具收据时效、模型上下文顺序及跨崩溃一致性。
4. 多 Agent 的预算聚合、授权继承和恢复协议。
