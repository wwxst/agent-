# 04 · 工具系统、审批与安全边界

> 状态：设计草案。安全规则定义最低交付要求；没有运行沙箱时不得标记为“安全实现”。

## 一、威胁模型

不可信输入包括：用户提供的非授权文件、仓库 README/代码注释、网页、MCP 结果、Tool Host 输出、模型生成文本以及第三方 Skill。攻击形式包括提示注入、路径逃逸、符号链接绕过、命令注入、凭据泄露、网络外传和高权限工具链间接调用。

信任边界：

- 人的显式请求定义目标；模型只提出动作建议。
- Policy Engine 决定动作是否允许；Tool Host 负责在操作系统层执行限制。
- 前端不得签发或伪造权限；所有审批决定由后端核验身份与精确参数。
- 插件或 Skill 的声明不能自动扩大内核拥有的权限。

## 二、工具合同

每个工具必须声明：

| 字段 | 意义 |
| --- | --- |
| name / version | 稳定名称、版本 |
| inputSchema / outputSchema | 参数与结果的结构化约束 |
| risk | 只读、工作区变更、外部副作用、危险 |
| capabilities | 文件路径、命令、网络域名、工作区等权限需求 |
| timeout / maxOutputBytes | 执行界限 |
| idempotency | 只读、幂等、条件幂等或非幂等 |
| cancellation | 支持/不支持及取消保证范围 |

注册工具时拒绝重复名称或冲突版本。动态发现的 MCP 工具统一附带来源标识，不允许伪装为内建安全工具。

## 三、MVP 工具

- **Read**：只读取许可目录内的普通文件，限制大小、编码与文件类型。
- **Glob/Grep**：目录范围检查、数量上限、超时与输出上限；禁止通过遍历隐藏目录绕开权限。
- **Write**：创建/覆盖文件，默认需要修改权限；建议使用临时文件加原子替换。
- **Edit**：基于文件当前版本或 Hash/Tag 的条件修改，检测旧版本并拒绝盲写。
- **Bash**：单独隔离进程、固定工作目录、受限环境变量、输出上限和超时；没有隔离时默认拒绝。
- 后续 Browser、FFmpeg、外部 API 均沿用同一 ToolCall + Capability + 审批框架。

## 四、审批模型

状态：not_required、pending、approved、denied、expired、revoked。

审批请求最少包含：审批 ID、Session ID、Turn ID、ToolCall ID、规范化参数哈希、工具风险、可读摘要、到期时间和目标执行宿主。

必须保证：

1. 工具名称或参数发生变化时原审批失效。
2. 一次审批不能被拿去批准另一 Session 或另一个 ToolCall。
3. 审批过期、网络断开或等待超时不能被默认为同意。
4. 授权前准备操作不得发生外部副作用。
5. 批准不是永久权限，长期授权需要单独有范围、有期限的 Capability。
6. Hook 的 allow 建议不能覆盖宿主拒绝或操作系统限制。

## 五、强制执行的能力模型

Capability 应与 Session、工作区、宿主、工具类别、路径或网络范围绑定。Kernel 只传递服务端签发或可信连接附带的能力引用，Tool Host 独立验证。

工作区检查需处理规范化路径、符号链接、硬链接、挂载点、竞态以及文件替换；不得只做 `startsWith(workspace)` 字符串判断。对高风险写操作优先使用操作系统支持的受限目录句柄或隔离容器。

工具进程的环境变量默认最小化；不传递无关 API Key、用户凭据、Git Token。日志和异常消息要脱敏。

## 六、隔离等级

| 等级 | 执行方式 | 是否可用于高风险工具 |
| --- | --- | --- |
| 0 | 同进程直接执行，依赖提示词约束 | 不可 |
| 1 | 子进程与基本工作目录检查 | 仍不等于安全沙箱 |
| 2 | OS/容器隔离，受限文件、网络、资源 | 在经过测试和审批后可 |
| 3 | 独立受控远程 Host，细粒度能力、审计 | 可作为高级部署目标 |

隔离级别必须由实际可验证技术特性判定，不能只因为使用 Rust、Docker 或某种编程语言就推定安全。

## 七、工具运行与审计

- Kernel 先持久化 ToolCallPrepared 与审批记录，才发起执行。
- Tool Host 返回 started / result / outcome_unknown，所有结果关联调用 ID。
- 外部操作不能确认结果时进入 unknown，不自动重放。
- 审计日志包含审批人、参数摘要、宿主身份、开始/结束时间和工具结果分类，不记录完整秘密。
- 运行中的取消通常只是尽力而为；尤其 Shell、外部请求可能已产生部分副作用。

## 八、验收与安全测试

至少包含：非法路径、符号链接路径逃逸、参数篡改、重复审批提交、过期批准、跨会话授权、工具结果提示注入、命令超时、输出超限、进程杀死后状态未知、无隔离环境拒绝危险执行。
