# Agent 内核中文技术术语对照表

> 文档叙述采用中文，接口名称、代码标识、第三方产品名称保留英文。首次出现时推荐采用“中文名称（英文术语）”。

| 英文术语 | 建议中文名称 | 使用说明 |
| --- | --- | --- |
| Agent Kernel | 智能体内核 | 管理执行循环、会话状态及工具入口的核心 |
| Agent Loop | 智能体执行循环 | 模型响应、工具调用、工具结果回填的迭代流程 |
| Session | 会话 | 一段可追踪的交互与事件历史 |
| Turn | 交互轮次 | 一次用户输入及其后续模型/工具执行 |
| Step | 执行步骤 | 一个模型调用或一次明确的内部执行阶段 |
| Provider | 模型适配器 | 负责模型协议而非工具副作用 |
| Tool Host | 工具执行宿主 | 实际执行并独立复核权限的可信组件 |
| Tool Registry | 工具注册表 | 工具名称、Schema、版本与能力声明 |
| ToolCall | 工具调用 | 具有唯一 ID、工具名称及参数的请求 |
| Intent | 执行意图 | 工具启动之前的可信持久记录 |
| Receipt | 执行收据 | 工具宿主对执行过程或结果的记录 |
| Outcome Unknown | 结果未知 | 外部副作用可能已发生，但证据不足 |
| Event Journal | 事件日志 | 记录权威状态演进的持久事件序列 |
| EventStore | 事件存储接口 | 事件读写、顺序和并发约束 |
| Snapshot | 状态快照 | 可由事件重建的状态投影 |
| Checkpoint | 上下文检查点 | 对历史消息的可验证摘要或投影 |
| Writer Lease | 写入租约 | 临时允许某个执行者写入会话 |
| Fencing Token | 隔离令牌 | 防止过期执行者继续写入的单调版本凭据 |
| Compare-and-Swap (CAS) | 比较并交换 | 通过期望版本阻断竞争写入 |
| ACK | 确认回执 | 只表示特定阶段已被确认，不等于执行成功 |
| Command Inbox | 命令收件箱 | 持久接受命令并处理重复投递 |
| Command Dispatcher | 命令分发器 | 绑定命令与轮次并协调首次执行 |
| Steering | 执行中指令调整 | 在规定边界向活动轮次注入新指令 |
| Follow-up | 后续跟进消息 | 通常在下一轮/步骤消费的输入 |
| Control Plane | 控制面 | 身份、授权与执行控制接口 |
| Fail Closed | 失败时默认拒绝 | 无法证明安全时不放行 |
| Idempotency | 幂等性 | 重复请求不产生额外执行后果 |
| Reconciliation | 证据对账 | 对比 Kernel 和 Tool Host 的执行记录 |
| Sandbox | 沙箱 | 利用隔离机制限制可访问资源与行为 |
| Bubblewrap | Bubblewrap 容器隔离工具 | Linux namespace 隔离启动工具 |
| cgroup | 控制组 | Linux 资源配额与进程组管理机制 |
| seccomp | 系统调用过滤 | Linux 进程系统调用限制机制 |
| SSE | 服务器发送事件 | 模型/客户端单向事件流机制 |
| SDK | 软件开发工具包 | 对外暴露的编程接口与配套工具 |
| CLI | 命令行界面 | 终端交互入口 |
| IPC | 进程间通信 | 子进程与宿主进程交换消息的机制 |
| ADR | 架构决策记录 | 记录选择、取舍、状态与证据 |
| PTC | 程序化工具调用 | 研究中的工具编排模式 |
| Scope | 能力作用域 | 限制插件、工具及资源的生效范围 |
| Hooks | 钩子 | 在预定生命周期点执行扩展逻辑 |
| Skills | 技能 | 面向任务的约定、知识和能力组合 |
| MCP | 模型上下文协议 | 外部工具和上下文服务接入标准 |
| Subagent | 子智能体 | 受父任务约束的独立工作单元 |

## 翻译约定

1. 不改写程序符号，例如 `runAgentLoop()`、`tool.intent`、`FencingToken`、`OutcomeUnknown`。
2. 不翻译正式产品、项目与组织名称，例如 Claude Code、OpenAI Codex、Pi Agent、DeepSeek Harness。
3. 不翻译代码块中的协议字段、JSON Key、命令行参数和文件路径。
4. 已有不同中文译名时，优先统一叙述中的称呼，避免破坏历史证据和原始引用。
5. “已测试”“已实现”“待验证”等状态词必须指明对应版本，不凭语言润色提高证据等级。
