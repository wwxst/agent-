报告 41 已完成 Bash、MCP ordinary auto-background、SEP-2663 task 与 Remote Host 的静态取消时序矩阵。

报告 42 完成 Subagent 第一轮生命周期追踪：

- Agent Tool 通过 ho 决定 sync/async；sync 使用 parent AbortSignal，自动后台化时解除；async 使用独立 controller。
- parentAgentId 代表 lineage/descendant tree；ownerAgentId 代表通知与 keepalive owner。resume 可转移 owner 而保留原 parent lineage。
- Agent loop W7 独立运行；transcript JSONL 与 .meta.json sidecar 分离；resume 读取二者并启动新 W7 loop，不恢复旧 Promise/stream/AbortController。
- parent keepaliveReasons 可使 parent 处于 completed-but-parked；child 完成后通知 owner 并释放 keepalive。
- TaskStop 有 caller ownership check、stoppedByUser 持久 marker，以及 completed-but-parked parent 的 descendant cascade；running parent 的 async child 不通过 parent AbortSignal 自动停止，通知可 rehome 到 main。
- Worker adoptedPrefill 会验证 parent transcript 与 metadata，链接 Agent transcript/sidecar 并将 carried Agent task 重建为 completed；它不恢复 Agent loop。Shell 则另有 PID identity reattach。

## 8. 本轮续接标记

**本轮已证实：**

- Agent Tool 根据 caller/agent/background/isolation policy 分 sync 与 async；sync 的 parent abort relay 可在自动后台化时解除，async Agent 使用独立 controller。
- parentAgentId 与 ownerAgentId 分别用于 lineage/cascade 和通知/keepalive；resume 可转移 owner 而保留 ancestry。
- Agent transcript JSONL 与 metadata sidecar 独立；resume 读取历史 transcript + metadata，创建新 task record 并启动新 W7 loop。
- TaskStop 对 agent 有 owner check、stoppedByUser marker 和条件性 descendant cascade；completed-but-parked parent 与 running parent 的 stop 语义不同。
- worker adoption 验证 launch lineage；Agent record 可被重建为 completed，Shell process 可按 PID identity reattach；两者恢复机制不同。

**下一次新对话第一任务：** 深入 Agent transcript × context compaction，核对 tool_use/tool_result、附件、parent lineage、summary 与 resume 的连续性；然后补 remote Agent worker lifecycle。报告 33–42 均为静态源码研究，不是最终架构裁决；不允许开始开发。
